IHSVH

Design System

HTML Style Guide

This guide defines the visual language for all IHSVH HTML documents. The system is built on three principles: restraint over decoration, gold as structural signal, and form following epistemic register. Every typographic and color decision should serve the hierarchy of the content, not announce itself.

01

Color

Seven variables. Light and dark modes. Gold is never decorative — it marks structural weight: section numerals, derivation numbers, vertical rules, key symbolic markers, authorial notes. When gold appears, it should signify architecture rather than commentary.

Color Use Rules

var(--ink)

Primary body text. Thesis statements. Section headings. All load-bearing prose.

var(--gold)

Authorial notes. Section numerals. Derivation numbers. Vertical and horizontal rules. Symbolic term definitions. Summary borders. Never body prose.

var(--cream-dark)

Blockquote text. Front matter prose. Secondary body. Set-apart quoted material.

var(--warm-grey)

Structural labels (DEFINITIONS, DERIVATION, NOTE TO THE READER). Appendix section numbers. Author attribution. Citation text. Scaffolding — present but recessive.

02

Typography

Three families. Each carries a specific register. Never interchange them — the reader learns the code.

EB Garamond — Body

18.5px / line-height 1.72. All body prose, notes, blockquotes, theses. The governing voice of argument. Italic for authorial commentary. Bold (700) for thesis statements only.

Cormorant Infant — Display

Section headings (h2), title (h1.work), appendix title, appendix section headings (h4). The ceremonial voice. Uppercase for section headings. Italic for titles and appendix headings.

Layout

Single column. Maximum 660px. Centered. The constraint is the design — text width controls reading rhythm more than any typographic choice.

04

Title Block

Centered. Energy is quiet at the entry — the cover invokes and names; it does not perform. The gold vertical line descends from the title block as a visual signal of descent into the text. Order: Invocation → Title → Work Label → Gold Line.

Spacing: author sits 8px below the top rule, 28px above the title. Title has 42px below before the work label. Work label has no bottom margin — it sits flush. The first body paragraph after the title block has 5rem top margin to give the gold descender room.

05

Section Architecture

Each section opens with a rule, a gold numeral, and a Cormorant heading. The numeral and heading are separate elements that read as one unit — tight margin between them. The thesis follows as the first statement of the section's governing claim.

Live Example
IThe Ground

The heart moves toward what it apprehends as good.

In the heart, apprehension and movement are one act. To see as good is already to move.

Movement belongs to apprehension itself, not to what follows it.

Where sight is true, movement is toward the maximal good. Where sight is partial, movement is toward a genuine but lesser good.

Formal Apparatus

Definitions and derivations. The deflist uses flex layout so definition text wraps flush — never bleeds under the gold term. Derivation uses CSS counter with gold numbers and italic grey labels as parenthetical annotations at the end of each step.

Definition List

G God: the maximal good, independent of any apprehender.

x the heart.

S(x,y) x apprehends y as good.

.deflist p {
  display: flex; align-items: baseline;
  gap: 0 0.5rem; margin: 0 0 1.4rem;
}
.deflist strong {
  color: var(--gold);
  flex-shrink: 0; min-width: 3.5rem;
}
Derivation List

Numbered list with gold counter. Each step ends with an italic grey label in parentheses: (Axiom), (Ontology), etc. The label is a quiet annotation, not part of the step.

ol {
  margin: 0.5rem 0 0.5rem 0.5rem;
  padding-left: 0; list-style: none;
  counter-reset: deriv;
}
ol li {
  counter-increment: deriv;
  margin-bottom: 1.4rem;
  position: relative; padding-left: 2rem;
}
ol li em { color: var(--warm-grey); }
ol li::before {
  content: counter(deriv) ".";
  position: absolute; left: 0; top: 0;
  color: var(--gold); font-weight: bold;
}

Summary

The distilled theorem. Centered, italic, between two gold rules. Each proposition is a separate paragraph with exaggerated vertical margin — tight line-height within a line, generous space between propositions. The document's argument comes to rest here, not to a conclusion.

God is the maximal good.

True apprehension of God is movement toward God with nothing withheld.

Grace is this act: God's giving and the heart's movement as one.

Practice is the refinement of sight.

Embodiment is its continuity in matter.

10

Design Principles

Gold Marks Structure, Not Decoration

Every gold element signals epistemic weight: a numbered section, a formal derivation, a governing proposition, an authorial intervention. When gold appears, the reader should feel: this is load-bearing. Gold used decoratively collapses the signal.

Richness Through Restraint

Thin strokes. Low-opacity fills. No glows. No shadows. No gradients. The aesthetic is drafting and technical drawing — precision, not atmosphere. Every decorative impulse should be tested against the question: does this serve the hierarchy of the content?

Form Follows Epistemic Register

Typography and color encode the register of each element. Thesis = weight. Note = gold italic. Structural label = tracked uppercase grey. Body = plain. The reader learns this code quickly and navigates by it. Mixing registers — styling a body paragraph like a note, or a label like a heading — breaks the map.

Energy Builds Toward the End

The cover is quiet — it names without performing. Visual weight accumulates as the argument deepens. The summary is the most ceremonially treated element: centered, bordered in gold, each proposition given room to breathe. The document should feel like it arrives somewhere, not like it announces itself and trails off.

Dark Mode Parity

Dark mode is not an inversion — it is the same document seen in different light. Background: #1F1F1D. Gold dims slightly to #BC9836 to avoid harshness. All variables are scoped to :root inside a prefers-color-scheme: dark media query. Never hardcode hex values outside variable definitions.

File Naming Convention

Always lowercase kebab-case. Documents derived from a specific author's work are prefixed with the author's last name: hulse-cube-of-space.html, case-true-and-invisible.html. Joshua's own works carry no prefix: the-chariot.html, axiom-of-the-heart.html.
